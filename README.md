# audhd-toolkit

> Tools, skills, and workflows I built to work with my AuDHD brain instead of against it.
## The idea

I'm not fixing how I think. Squirrel brain or not, it's not changing, and I'm done arguing with it.

So the tools take load off instead of demanding discipline. What runs out for me isn't willpower, it's a daily budget of focus. These tools and workflows aid me in spending it carefully.

## Why they're shaped like this

- **Associative thinking.** Everything looks equally worth doing. I need somewhere to park distractions, not a to-do list that commits me to every stray thought.
- **The RAM model.** An interruption doesn't pause a task, it wipes it. So I build for resuming, not for staying organized.
- **The entropy cycle.** Mess builds, I clean, it builds again. I handle it on a schedule instead of waiting for the dread to hit.

## What's inside

- **Reflect tools.** They ask the questions and make me answer. The thinking stays mine. This is the real work.
- **Entropy tools.** Scheduled cleanup, so clutter gets handled on a rhythm.
- **Scaffolding.** Context that loads on demand, ways back into paused work, places to put things.

Things that stop earning their place get cut. That's the system working, not breaking.
