# audhd-toolkit

Meta-project and index for Anna's ADHD support system. This repo is the single
source of truth for what the toolkit is, why it exists, and how the pieces fit
together.

## Purpose

Build tools, skills, and workflows that work with an AuDHD brain instead of
against it. The scarce resource isn't willpower — it's a daily budget of focus.

## Principles

- **RAM model.** An interruption doesn't pause a task, it wipes it. Everything
  is built for resuming, not for staying organized.
- **Entropy cycle.** Mess builds, I clean, it builds again. Handled on a
  schedule instead of waiting for the dread to hit.
- **Associative thinking.** Everything looks equally worth doing. Tools exist
  to park distractions, not to commit to every stray thought.
- **n=1.** Tuned to one brain. What works for others is context, not
  prescription.
- **Earn your keep.** Tools that stop being useful get cut. That's the system
  working, not breaking.

The components are indexed once, in the Components table in `README.md` —

## Vocabulary

- **Entropy tools** — scheduled cleanup routines that handle accumulating clutter
- **Reflect tools** — prompt-driven tools that ask questions and let the user answer. The thinking stays theirs.
- **Scaffolding** — context that loads on demand, ways back into paused work, places to put things
- **Inbox** — raw, unprocessed idea or note. Needs human attention before it enters the triage pipeline.

## Design constraints

- Tools demand scaffolding, not discipline. If it needs willpower to use, it's
  designed wrong for this user.
- Focus budget is the scarce resource. Every interaction should save more
  focus than it consumes.
- Duplication across repos is avoided. Each piece of the toolkit lives in one
  place; this repo is the index that links them.
