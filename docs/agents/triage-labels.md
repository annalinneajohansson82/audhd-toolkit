# Triage Labels

| Canonical role | Label in our tracker | Meaning |
|----------------|---------------------|---------|
| `inbox` | `inbox` | Raw, unshaped idea. Needs human processing before it enters the pipeline |
| `needs-triage` | `needs-triage` | Ready to be evaluated |
| `needs-info` | `needs-info` | Waiting on more context |
| `ready-for-agent` | `ready-for-agent` | Fully specified, Hermes can handle autonomously |
| `ready-for-human` | `ready-for-human` | Needs human involvement |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role (e.g. "apply the AFK-ready label"), use the
corresponding label string from this table.
